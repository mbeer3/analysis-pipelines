# CRISPR Flow Cytometry Pipeline

This directory contains scripts for processing and analyzing CRISPR flow-cytometry screen data.

## FASTQ Clipping

### Read Processing

- **Script:** `FASTQ_Clipping`
- **Input:** FASTQ reads
- **Output:** Collapsed guide sequences and read counts
- **Executable:** `fastx_trimmer-0.0.14`, `fastq_quality_converter-0.0.14`, `fastq_quality_filter-0.0.14`, `fastx_collapser-0.0.14`, `fasta_formatter-0.0.14`

The script extracts bases 31–50, filters reads by quality, collapses identical sequences, and reports each sequence with its read count.

---

## Guide Count Matrix Generation

### Sequence-to-Library Mapping

- **Script:** `joinRNAi.py`
- **Input:** Guide library and one or more sequence-count files generated by `FASTQ_Clipping`
- **Output:** Guide-by-sample count matrix
- **Python:** `2.7.18`
- **Python imports:** `sys`, `os`, `argparse`

The script matches counted sequences to the guide library, records alternative guide names for duplicated sequences, and assigns a count of zero when a guide is absent from a sample.

---

## PDX1 CRISPR Screen Analysis

### Guide-Level and Region-Level Analysis

- **Script:** `CodeforPDX1_Screens.R`
- **Input:** PDX1 guide alignments, guide count tables, non-targeting controls, and Safe Harbor controls
- **Output:** Normalized guide counts, log2 fold changes, moving-window statistics, IDR results, significant regions, BED files, BigWig files, CSV files, and plots
- **R:** `4.1.3`
- **R packages:** `data.table-1.14.2`, `metaseqR2-1.6.1`, `idr-1.3`, `plotly-4.10.0`, `ggplot2-3.3.5`, `gridExtra-2.3`, `rtracklayer-1.54.0`
- **Executable:** `cut`

The script maps PDX1 guides to genomic coordinates, normalizes positive and negative flow-cytometry fractions, calculates replicate-specific log2 fold changes, performs moving-window analysis, evaluates replicate agreement with IDR, and identifies significant regulatory regions.

---

## Definitive Endoderm Gene CRISPR Screen Analysis

### Guide-Level Analysis

- **Script:** `CodeforDEgenes_Screens.R`
- **Input:** Replicate count sheets, off-target-filtered guide lists, ATAC-seq peaks, TAD annotations, and competent or incompetent region annotations
- **Output:** Normalized guide counts, log2 fold changes, z-scores, IDR results, significant guides, RDS files, CSV files, and plots
- **R:** `4.1.3`
- **R packages:** `openxlsx-4.2.5.1`, `idr-1.3`, `GenomicRanges-1.46.1`, `Gviz-1.38.3`, `dplyr-1.0.8`, `scales-1.1.1`, `ggplot2-3.3.5`, `cowplot-1.1.1`, `ArchR-1.0.2`, `BSgenome.Hsapiens.UCSC.hg19-1.4.3`, `rtracklayer-1.54.0`, `IRanges-2.28.0`

The script analyzes CRISPR screens targeting the definitive endoderm genes `MIXL1`, `EOMES`, `SOX17`, and `GATA6`. It filters guides, normalizes replicate counts, calculates guide-level effects, evaluates replicate consistency using IDR.
